♿ Accessibility
معايير الوصولية — WCAG 2.1 AA
المعيارالتطبيق في Storify
Color Contrastنسبة تباين 4.5:1 على الأقل للنص — تم التحقق بـ Lighthouse
Focus Statesكل الأزرار والـ inputs عندها focus ring واضح (3px brand-500)
Keyboard NavigationTab order منطقي — كل الـ modals تدعم Escape للإغلاق
Screen Readersaria-label على الأيقونات — aria-live للـ toast notifications
Form Labelsكل input عنده label مرتبط بـ htmlFor/id
Error Statesالأخطاء مش بس بالـ color — في icon وnص واضح
Motionprefers-reduced-motion يوقف الـ animations
🌐 RTL Guidelines
تصميم الـ RTL (Arabic) — قواعد خاصة بـ Storify
العنصرقاعدة RTLمثال
Layout Directiondir="rtl" على الـ html elementSidebar على اليمين، Content على اليسار
Text Alignmenttext-align: right افتراضيالأرقام والكود لازم تفضل LTR
Numbers & Amountsdir="ltr" على الأرقام1,250.00 ج — مش ج 1,250.00
Icons DirectionLucide بتدعم RTL تلقائياًالأسهم والشيفرون بتتعكس
Form Fieldsالـ placeholder والـ value عربيplaceholder="مثال: تيشيرت..."
Keyboard Shortcutsنفس الـ shortcuts — مفيش تغييرF3 = بحث، Enter = تأكيد
Date Formatيوم/شهر/سنة28/04/2026 أو 28 أبريل 2026
Time Format12-hour مع AM/PM بالعربي2:30 م أو 02:30 PM
CSS Variables — RTL Specific
/* RTL — في Storify دائماً dir="rtl" */ /* Padding: Right يعني في اتجاه النص (Start) */ .sidebar-link { padding-right: 16px; /* بجانب الـ nav item */ border-right: 2px solid transparent; /* الـ active indicator */ } /* الأرقام المالية — دائماً LTR */ .amount { direction: ltr; font-family: var(--font-mono); display: inline-block; } /* Input مع icon على اليمين (RTL = Start) */ .input-group .input { padding-right: 40px; } .input-group .icon { right: 12px; }
